# SleepTalking_DREAMEEG_HCTSA_Test

This repository contains MATLAB scripts used to perform hctsa analyses on EEG recordings from the De Gennaro Sleep Talking dataset obtained from the DREAM database.

The primary aim of this repository is to evaluate whether the hctsa analysis pipeline can be applied to other EEG datasets with minimal modifications to preprocessing and analysis parameters.

## Dataset Information

* **Dataset:** De Gennaro Sleep Talking Dataset (DREAM Database)
* **Number of subjects:** 12
* **Number of recordings:** 22
* **Recordings used in this test analysis:**

  * `LV02.edf` (dreamful condition)
  * `LV03.edf` (dreamless condition)

* **Preprocessing parameters:**
  * `Sampling frequency after downsampling: 128 Hz
  * Bandpass filter: 0.75–30 Hz
  * Epoch length: 60 seconds
  * Epochs analysed: Final 6 epochs prior to awakening
  
## Software Requirements

* MATLAB R2022b
* hctsa v1.06

## Analysis Workflow

The scripts should be executed in the following order:

1. `preprocessing_sixcases_oneparticipant.m` 
   * Loads a single EDF file, epoch 60s segments from the last 6 minutes, bandpass filter and downsample
2. `run_hctsa_twosubjects.m`
   * Prepares the data matrix and input files to run HCTSA. This script is specifically coded for 6 samples from 2 participants each
3. `TS_Init_specified_parameters.m`
4. `TS_Compute_specified_parameters.m`
   * This step is intended to be run on MASSIVE.
5. `Assigning_variables.m`
   * Creates the variables list for this specific dataset.
6. `Filter_hctsa_output.m`
   * Removes constant values, errors, and special-valued outputs(i.e., NANs)
7. `classification_analysis.m`
   * Across-subject dream classification
8. `consistency_analysis.m`
  * Within-subject dream classification

**Important:** Save the output generated by each script, as it is required as input for each subsequent script.

## Additional Functions

The following functions are required for `consistency_analysis.m`:

1. `getDNV.m`
2. `getConsistency2r.m`
